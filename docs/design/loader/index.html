RISK WISE splash — design comparison

Each frame renders at 480×320 (proposed splash size, up from current 300×200). Status text cycles every ~1.8s to simulate live boot phases.

1. Minimal polish

Closest to today: dark teal background, gear keeps spinning, single status line below it. Adds wordmark + version. Lowest risk, smallest visual jump.

2. Brand-forward

Gradient backdrop, logo mark + wordmark lockup, indeterminate shimmer bar replaces gear. Feels like a modern desktop app splash (think VS Code, Figma).

Current splash for reference: 300×200, plain grey #565656, gear only, no text.
